# Model management

The default dense encoder is sentence-transformers/all-MiniLM-L6-v2. The visual encoder is the merged vidore/colpali-v1.3-merged checkpoint loaded by colpali-engine. The two exact revision hashes are in .env.example. The merged checkpoint supplies both the PaliGemma backbone and the learned ColPali projection. Deployment owners must review the model licenses. [MiniLM model card](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) · [ColPali model card](https://huggingface.co/vidore/colpali-v1.3-merged)

Models load on first use. The registry tracks unloaded, loading, ready, failed and unloading states. A per-model lock prevents duplicate initialization. Setting AI_LAZY_MODEL_LOADING=false preloads both. AI_REQUIRED_MODELS is a JSON array of aliases that must load before serving. Offline mode resolves a cached revision to a local snapshot before calling the libraries. The download script runs explicitly and leaves large files outside Git and the image. Configure immutable revisions when changing models. The ColPali adapter expects a checkpoint compatible with the ColPali model and processor classes.

AI_DEVICE=auto tries CUDA, MPS, then CPU. Model-specific settings can override it. CPU uses FP32. Accelerator dtype is validated against device capability. On a recognized unsupported operation or accelerator allocation failure, the eligible model can be reloaded on CPU. AI_ALLOW_DEVICE_FALLBACK=false disables this behavior. COLPALI_BATCH_SIZE defaults to one. Limit simultaneous inference with AI_MAX_CONCURRENT_INFERENCES. Native kernels cannot be interrupted safely inside a Python thread. A request timeout returns a structured error and holds its concurrency slot until the running operation actually exits. Size worker resources and upstream deadlines for the selected device. Multiple OS processes have distinct model caches in memory.

Dense output shape is [dimensions]. MiniLM truncates at the model's configured token limit. Choose chunk size for your tokenizer. Batch and query use the same revision and normalization setting. ColPali document and query tensors have shape [valid_sequence_positions, embedding_dimension]. All official processor positions with a nonzero attention mask are retained, including the model's query augmentation and visual input tokens. The two sequence lengths can differ. Text and visual embedding spaces are independent.

Tensor format v1 is NumPy NPY, C-order, little-endian float32, without pickle. Each artifact includes checksum, byte length, shape, dtype, dimensions, model ID, revision, processor, precision, timings and device. The storage checksum covers the actual NPY bytes. The reader checks checksum, declared shape and type. The benchmark computes reference MaxSim as the sum over query positions of their maximum dot product against page positions. Retrieval owns the production ranking pipeline.

The locked Windows and Linux installs select CPU PyTorch wheels. macOS uses its native wheel with MPS support. For NVIDIA Linux x86-64 build with `docker build --build-arg TORCH_ACCELERATOR=cu128 -t enterprise-search-ai:cuda .`. Install a compatible host driver and NVIDIA Container Toolkit and run with `--gpus all`. Use the same model cache and tensor format. Physical Apple MPS inference was verified with FP32 MiniLM and FP16 ColPali. CUDA and Windows execution need separate target-machine verification.
